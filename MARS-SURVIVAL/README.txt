MARS SURVIVAL - PROTOTIPO FUNCIONAL
===================================

REQUISITOS
- JDK 17 o superior
- Apache NetBeans con soporte para proyectos Maven
- Conexión a internet la primera vez para descargar dependencias Maven

ABRIR EN NETBEANS
1. Descomprime MARS-SURVIVAL.zip.
2. Abre NetBeans.
3. Selecciona File > Open Project.
4. Elige la carpeta MARS-SURVIVAL (la que contiene pom.xml).
5. Espera a que Maven descargue las dependencias.
6. Ejecuta MarsSurvivalApplication.java con Run File o ejecuta el proyecto.

ABRIR LA APLICACIÓN
En la computadora abre:
http://localhost:8080

Para probarla desde un celular conectado a la misma red Wi-Fi:
1. Averigua la dirección IP local de la computadora.
2. En el celular abre http://IP-DE-LA-COMPUTADORA:8080
3. Permite Java en el firewall si el sistema lo solicita.
Ambos dispositivos deben estar conectados a la misma red. No uses una red pública.

FUNCIONES INCLUIDAS
- Mapa esquemático interactivo con cinco regiones marcianas.
- Ficha descriptiva de cada región.
- Selección de origen y destino.
- Indicadores simulados de oxígeno, agua, energía y provisiones.
- Avance de soles, reposición simulada y reinicio de misión.
- Alertas de misión.
- Diseño adaptable a computadora y celular.

IMPORTANTE
Este es un prototipo educativo. El mapa es esquemático y no está a escala.
Las ubicaciones y datos descriptivos son referencias generales; los porcentajes
de supervivencia y los cambios de recursos son ficticios para el desafío.
El proyecto necesita conexión a internet la primera vez para descargar Spring Boot
y sus dependencias. Después puede ejecutarse localmente.
